# 🧠 agent-mesh-router — কীভাবে কাজ করবে (সহজ বাংলায়)

> এই ডকুমেন্টে ৩টা প্রশ্নের উত্তর আছে:
> ১. ম্যানেজার কে হবে? রেট লিমিট / মানের সমস্যা হবে কি?
> ২. **ডাইরেক্ট মোড** — ম্যানেজার কাজ ভাগ করে দেয়
> ৩. **গ্রুপ মোড** — সবাই একসাথে কথা বলে, একে অন্যকে রিপ্লাই দেয়

---

## ১️⃣ সবচেয়ে বড় সত্যি কথা

> ### 🎯 ম্যানেজারকে "বুদ্ধিমান" হতে হবে না — **পোস্টম্যান** হলেই যথেষ্ট।

- **কাজটা কে করবে?** → এজেন্টরা (OpenHands, OpenCode, Cline, Claude Code)
- **কাজটা কে ভাগ করবে?** → ম্যানেজার (শুধু "কে কোথায়" ঠিক করে)

👉 যে মডেল "কে কোথায়" ঠিক করে, তার বড় মাথা লাগে না।
👉 তাই **ফ্রি মডেলই যথেষ্ট**, আর **রেট লিমিটও প্রায় লাগেই না**।

---

## ২️⃣ ম্যানেজারের ৪টা ধাপ (ধাপ ০ সবচেয়ে সস্তা)

| ধাপ | কী করে | খরচ | কখন |
|---|---|---|---|
| **০** 🔍 কীওয়ার্ড রুল | `@claude`, `@opencode`, `bug`, `doc` দেখে নিজেই বুঝে নেয় | **০ কল** | ৭০% কাজ |
| **১** 🆓 OpenCode ফ্রি DeepSeek | না বুঝলে এটাকে জিজ্ঞেস করে | **০ টাকা** | ২৫% কাজ |
| **২** 🟢 Gemini key | উপরের দুটো না পারলে | ফ্রি কোটা | ৫% কাজ |
| **৩** 💾 ক্যাশ | একই প্রশ্নের উত্তর মনে রাখে | **০ কল** | পুনরাবৃত্তি |

> ✅ **ফল:** ১০০টা মেসেজে ম্যানেজারের আসল AI কল লাগে **~৫টা**।
> তাই রেট লিমিট **সমস্যাই না** — ৫০০ অ্যাকাউন্টের দরকার নেই।

---

## ৩️⃣ রেট লিমিট নিয়ে সতর্কতা ⚠️

| 🚧 ঝুঁকি | 💬 কী হয় |
|---|---|
| 🔁 ৫০০ Gemini অ্যাকাউন্ট ঘোরানো | Google এর নিয়ম ভাঙা — **অ্যাকাউন্ট বন্ধ** হতে পারে ❌ |
| 🖐️ OpenHands ফ্রি | **দিনে ~১০টা কাজ** (conversation) — গ্রুপ মোডে দ্রুত শেষ |
| 🔄 লুপ | এজেন্টরা একে অন্যকে ডাকতে থাকলে অসীম খরচ |

### ✅ প্রতিকার
- ২–৩টা key + **fallback chain** (একটা শেষ → পরেরটা)
- OpenHands → শুধু **আসল কাজে**; গ্রুপ চ্যাটে **OpenCode / Cline** (ফ্রি)
- **কঠিন সীমা:** প্রতি আলাপে সর্বোচ্চ ৮ বার কথা, এক জোড়া এজেন্ট পরস্পরকে সর্বোচ্চ ৩ বার

## ৪️⃣ মোড ১ — 🎯 ডাইরেক্ট মোড

```
👤 আপনি → 🧠 ম্যানেজার → (এক বা দুইজন এজেন্ট) → 📋 ফলাফল
```

- ম্যানেজার ঠিক করে **কে করবে**, শুধু তাকেই ডাকে
- সবচেয়ে **সস্তা ও দ্রুত** — এটাই ডিফল্ট
- উদাহরণ: "টেস্ট ফিক্স করো" → 🧑‍💻 OpenCode

---

## ৫️⃣ মোড ২ — 👥 গ্রুপ মোড

### (ক) ব্রডকাস্ট — সবাই একসাথে
```
👤 "হাই"
   └─▶ 🖐️ OH   ┐
   └─▶ 🧑‍💻 OC   ├─ সবাই নিজের মতো উত্তর দেয়
   └─▶ 🟦 Cline┤   (একে অন্যর অপেক্ষা করে না)
   └─▶ 🟠 CC   ┘
```
👉 এখানে **ম্যানেজারের কোনো AI কল লাগে না** — শুধু "সবাইকে পাঠাও"।

### (খ) এজেন্ট ↔ এজেন্ট কথা 💬
- **গ্রুপ চ্যাট = একটা GitHub Issue** (বা রিপোতে একটা ফাইল)
- প্রতিটা এজেন্ট সেখানে লেখা **পড়ে**, নিজের মত **লিখে**
- কাউকে ডাকতে চাইলে **@mention** করে → সে জব ওঠে, উত্তর দেয়

```
🟠 Claude Code: "@cline এই ফাংশনটা ঠিক আছে?"
     └─▶ 🟦 Cline: "না, লাইন ৪২ এ সমস্যা"
             └─▶ 🟠 Claude Code: "ঠিক করলাম ✅"
```

✅ **হ্যাঁ, এটা সম্ভব** — আলাদা সার্ভার লাগবে না, GitHub Issue-ই যথেষ্ট।

| 💸 খরচ | সব ফ্রি টিয়ারই **সীমিত সময়ের জন্য** — বদলাতে পারে, নজরে রাখতে হবে |

## ৬.৫️⃣ ☤ Hermes — একজন **কর্মী** (ম্যানেজার নয়)

**সিদ্ধান্ত (মালিকের):** 🧠 **ব্রেইন = আমাদের কোড, GitHub Actions এ থাকে।** Hermes = বাকিদের মতোই একজন কর্মী।

| 🎭 ভূমিকা | কে |
|---|---|
| 🧠 **ব্রেইন / ম্যানেজার** | **আমাদের কোড** — `mesh/` (এই রিপোতে, GitHub Actions এ চলে) |
| 🤖 **কর্মী** | OpenHands · OpenCode · Cline · Claude Code · **Hermes** |

**তাহলে Hermes এর বিশেষত্ব কী?**
- 🧠 **স্মৃতি** — আগের কাজ/সিদ্ধান্ত মনে রাখে (রাউন্ডের মাঝে কনটেক্সট দেয়)
- 🔁 **নিজে শেখে** — স্কিল বানিয়ে পরে পুনরায় ব্যবহার করে
- 📱 **রিমোট** — চাইলে Telegram থেকেও আলাদাভাবে চালানো যায়

**⚠️ যেসব দিকে খেয়াল:**
- মডেলে **৬৪ হাজার context + tool calling** লাগে (সব ফ্রি মডেলে হয় না)
- OpenRouter ফ্রি: **২০ রিকোয়েস্ট/মিনিট, ৫০/দিন** (একবার $১০ কিনলে ১০০০/দিন)
- Nous নিজেই বলে **Hermes 4 মডেল** Hermes Agent এর ভেতরে দেবেন না (ওটা চ্যাটের জন্য)
- কমান্ড: `hermes chat -q "<প্রশ্ন>"` — একবার প্রশ্ন, একবার উত্তর
