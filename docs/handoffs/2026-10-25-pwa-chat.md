# Handoff — মেশ চ্যাট PWA (2026-10-25)

**Asked:** "এটার জন্য ChatGPT-স্টাইল একটা web app বানাও — iPhone 17 Pro Max-এ PWA হিসেবে Add to Home Screen করে অ্যাপের মতো ব্যবহার করবো।"
**Priority:** 3 (agent infrastructure / tools)
**Role:** worker

**Done:**
- `docs/app/` — সম্পূর্ণ চ্যাট অ্যাপ: `index.html`, `app.css`, `app.js`, `js/md.js`, `js/api.js`, `js/store.js`, `sw.js`, `manifest.webmanifest`, `icons/*`
  - ChatGPT-স্টাইল: পাশের ড্রয়ার (চ্যাট লিস্ট), ইউজার/এজেন্ট বাবল, মার্কডাউন, টাইপিং ডট, কপি বাটন, সেটিংস শিট, ডার্ক/লাইট/অটো
  - iPhone: `viewport-fit=cover`, safe-area insets, `100dvh`, `apple-mobile-web-app-*`, apple-touch-icon 180
  - অফলাইন: সার্ভিস ওয়ার্কার (shell cache-first), চ্যাট localStorage-এ
  - 🟡 ডেমো মোড (কিছু লাগে না) / 🟢 লাইভ মোড (Worker ঠিকানা দিলে)
- `worker/` — Cloudflare Worker: `POST /api/chat` (Issue-এ `@mesh …` comment), `GET /api/messages` (comment → message), `GET /api/health`; পাসকোড গার্ড, CORS
- ডিপ্লয়: GitHub Pages → Source `main` + folder `/docs` (কোনো workflow লাগে না; App টোকেনে `workflows` পারমিশন নেই)
- `tools/make_icons.py` — PIL ছাড়াই আইকন PNG বানায়
- `tests/test_pwa.py` + `tests/js/worker_check.mjs` + `tests/js/dom_check.mjs` + `docs/app/tests/md.test.mjs`
