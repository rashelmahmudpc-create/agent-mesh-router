# 💸 টাকা ছাড়া Claude মডেল কোথায় পাবেন? — সহজ উত্তর

> **সোজা কথা:** Anthropic এর নিজের Claude মডেল **ফ্রি নয়**। কিন্তু **Claude Code চালাতে Claude মডেল লাগে না** —
> OpenRouter এর **`:free` মডেল** দিয়ে চলবে, **টাকা বা কার্ড কিছুই লাগবে না**।

---

## ১️⃣ Anthropic কী দেয় (টাকার হিসাব)

| জিনিস | দাম |
|---|---|
| Anthropic API key (Claude মডেল) | 💰 টাকা লাগে, কার্ড লাগে |
| Claude Pro / Max সাবস্ক্রিপশন | 💰 মাসিক টাকা |

👉 **আপনার দরকার নেই।** নিচের পথে যান। ⬇️

---

## ২️⃣ ফ্রি পথ — OpenRouter (কার্ড লাগে না) ✅

1. 🌐 যান → **`openrouter.ai/keys`**
2. 📧 **ইমেইল বা GitHub** দিয়ে সাইন আপ করুন — **কার্ড চায় না**
3. 🔑 **Create Key** → `sk-or-...` কপি করুন

### সীমা (ফ্রি)

| সীমা | কত |
|---|---|
| ⚡ গতি | মিনিটে **২০** রিকোয়েস্ট |
| 📅 দিনে | **৫০** রিকোয়েস্ট |
| 💳 একবার $১০ কিনলে | দিনে **১,০০০** (তবে টাকা লাগবে — আপনার দরকার নেই) |

---

## ৩️⃣ কোন মডেল লিখবেন? (`CLAUDE_MODEL`)

> ### ✅ সবচেয়ে নিরাপদ: **`openrouter/free`**
> এটা OpenRouter এর **অটো-রাউটার** — নিজেই একটা ফ্রি মডেল বেছে নেয়।
> কোনো মডেল বন্ধ হয়ে গেলেও কোড কাজ করতে থাকবে। 🎯

এটাই **ডিফল্ট** হয়ে গেছে — কিছু সেট না করলেও `openrouter/free` ব্যবহার হবে।

### ইচ্ছা হলে নির্দিষ্ট ফ্রি মডেল

| মডেল আইডি | কেন |
|---|---|
| `minimax/minimax-m3:free` | টুল ব্যবহারে ভালো |
| `z-ai/glm-5.2:free` | বড় context (২৫৬K) |
| `qwen/qwen3.8-27b:free` | হালকা, দ্রুত |
| `nvidia/nemotron-3-ultra-550b-a55b:free` | বড় মাথা, ভারী কাজ |
| `google/gemma-4-31b-it:free` | গুগলের মডেল |

> ⚠️ ফ্রি মডেলের তালিকা **প্রায়ই বদলায়** — লিংকে গিয়ে দেখে নিন: `openrouter.ai/models?max_price=0`

## ৪️⃣ সৎ সতর্কতা ⚠️

| ঝুঁকি | ব্যাখ্যা |
|---|---|
| 🧰 **টুল ব্যবহার** | Claude Code Anthropic এর ফরম্যাট ধরে বানানো। ফ্রি মডেলে **টুল কল মাঝে মাঝে ভাঙতে পারে** |
| 📉 **৫০ কল/দিন** | গ্রুপ চ্যাটে দ্রুত শেষ হবে — তাই `max_calls_per_run` সীমা মেনে চলুন |
| 🥇 **আসল কাজে** | কোড লেখানোর জন্য **OpenCode** (ফ্রি, key ছাড়াই) সবচেয়ে ভালো |

👉 **সাজেশন:** Claude Code কে "দ্বিতীয় মত" হিসেবে রাখুন। **প্রধান কর্মী = OpenCode**।

---

## ৫️⃣ কোথায় বসাবেন

**GitHub → Settings → Secrets and variables → Actions**

| নাম | ধরন | মান |
|---|---|---|
| `OPENROUTER_API_KEY` | 🔒 Secret | `sk-or-...` |
| `CLAUDE_MODEL` | 📋 Variable (ঐচ্ছিক) | `openrouter/free` বা উপরের যেকোনোটা |

👉 `CLAUDE_MODEL` না দিলেও চলবে — ডিফল্ট `openrouter/free`।
